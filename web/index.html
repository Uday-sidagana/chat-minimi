A SMALL TOUR, AT YOUR PACE

Meet Minimi

Try these steps in order. Buttons prepare a message; you choose when to send it. Keep Web · Auto selected for the search steps.

  1. Give it something to remember

    Send a detail in one chat. An explicit “Remember that…” pins a message; ordinary messages can also be recalled.

    I'm relocating to Bengaluru next spring.

  2. Recall it in a different conversation

    After the first reply finishes, start a new chat. This paraphrase tests cross-chat memory. Click an M1 citation to open the original message and timestamp.

    Which city am I moving to, and when did I mention it?

  3. Research something current

    Watch the search status, open the web citations, and expand Response details to inspect searches, timing and retrieved context.

    Find the latest stable Python release and its release date. Use official sources.

  4. Follow the conversation

    Ask this in the same chat as step 3. Minimi uses the previous question to interpret the follow-up.

    What about Node.js? Include the release date and official sources.

  5. Check what you asked, and when

    Choose your timezone below the composer. Compare the answer with the original questions in Memory → Timeline.

    What did I ask today? Include the times in my selected timezone.

  6. Keep control of your history

    Open Memory to search, filter by date, pin, export or clear history. Use the sidebar trash icon to delete a single chat. Web mode can be set to Auto, Always or Off. Use the stop button to interrupt a reply.

Memory belongs to this browser workspace and retrieval is bounded. Web sources and memory references help you check an answer; they do not guarantee every claim is correct.
